# Contributing

Issues and PRs are welcome.

## Reporting a problem

Open an issue with:
- Output of `termux-adb-doctor`
- Architecture (`uname -m`)
- Termux version (`apt list --installed 2>/dev/null | grep termux-tools`)

## Pull Requests

- Test on real Termux before opening a PR
- Keep `set -e` in all scripts
- Update CHANGELOG.md
